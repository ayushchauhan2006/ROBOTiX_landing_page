# ROBOFEST 2026 — Build Beyond Ordinary

A robotics festival landing page by **Ayush Chauhan**, created for the **ROBOTiX Club, NIT Raipur — Web & App Development recruitment challenge**.

## About me

I'm Ayush Chauhan, a third-semester student at NIT Raipur. I built this project as part of my application to the Web & App Development domain of ROBOTiX Club. I wanted to create a page that reflects my interest in web development and makes robotics feel interactive and approachable.

## About the project

ROBOFEST brings together robotics, AI, engineering, and innovation. This frontend project introduces the festival, highlights its competitions, and helps visitors explore event details and official registration updates.

The page includes a hero section, an introduction to Robofest, three featured competitions, a registration updates section, FAQs, and ROBOTiX branding. It is a student recruitment project, not the official festival website.

## Theme and design

The design takes its midnight-blue and electric-cyan palette from the official ROBOFEST website. Readable typography, clear headings, and responsive layouts keep the event information easy to explore. Space Grotesk is used for headings and DM Sans for body text.

The event identity leads the hero, supported by the tagline **“Build beyond the ordinary.”** A friendly robot and custom animated competition scenes bring movement to the page.

## Highlights

- **Interactive robot:** Bolt follows the cursor with its eyes and gentle neck movement, then waves and says “Hi!” when clicked or tapped.
- **Robowar:** two combat bots approach, collide, and recoil, with a spinning weapon and impact sparks.
- **Roborace:** three bots follow a circuit with individual speeds and light trails.
- **Robothon:** a robotic arm transfers a component alongside an animated code display.
- **Event details:** cards open dialogs with competition information and links to official pages.
- **Responsive navigation:** layouts adapt to desktop, tablet, and mobile screens.
- **Accessible interactions:** keyboard controls, visible focus indicators, collapsible FAQs, and reduced-motion support.

## Technologies

**React · HTML/JSX · CSS · JavaScript · SVG · Vite**

The interface uses Lucide React icons and Google Fonts. The robot and event scenes are drawn in SVG, with JavaScript and CSS handling their interactions and animation. No backend is required.

## Credits

I chose the technology stack and guided the design and revisions. **OpenAI Codex provided substantial assistance with implementation, styling, animations, and documentation.** The page is a custom implementation rather than an unchanged template.

Event information and the latest color direction reference the [official ROBOFEST website](https://robotix.nitrr.ac.in/robofest). The March 22–23, 2026 edition has concluded, so the page directs visitors to the club for future registration updates.
