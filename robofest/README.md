# ROBOFEST — Frontend Project

[View the live website](https://ayushchauhan2006.github.io/ROBOTiX_landing_page/)

Created by **Ayush Chauhan**, a third-semester, IT student at **NIT Raipur**, for the **ROBOTiX Club Web & App Development recruitment challenge**.

This folder contains the React application for my ROBOFEST landing page. Its midnight-blue and cyan theme is inspired by the official festival website, with readable typography and layouts for desktop and mobile.

The page features an interactive robot, animated Robowar, Roborace, and Robothon scenes, event detail dialogs, registration updates, and FAQs. It uses React, HTML/JSX, CSS, JavaScript, SVG, and Vite, with Lucide icons and Google Fonts.

I built this project with help from OpenAI Codex for the code, styling, and animations, while choosing the design direction and refining it along the way.

Read the [project overview](../README.md) for more about me, the design, features, and credits.
